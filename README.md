# TaskBoard (ระบบ To Do สไตล์ Trello สำหรับบริษัท)

ระบบจัดการงานสำหรับทีม มีผู้จัดการ (หลายคนได้) และพนักงาน ใช้ Node.js + SQLite ไม่ต้องติดตั้งแพ็กเกจเพิ่ม (ไม่มี `npm install`)

## เริ่มใช้งาน
ต้องมี Node.js เวอร์ชัน 22.5 ขึ้นไป (https://nodejs.org)

```
cd taskboard
npm start
```
เปิด http://localhost:3000 ครั้งแรกจะเป็นหน้า "ตั้งค่าครั้งแรก" ให้สร้างบัญชีผู้จัดการคนแรก

ข้อมูลเก็บที่ `data/taskboard.db` (สำรองข้อมูลโดยคัดลอกไฟล์นี้ตอนปิดระบบ)

## ตัวแปรสภาพแวดล้อม
| ชื่อ | ความหมาย |
|---|---|
| `PORT` | พอร์ต (ค่าเริ่มต้น 3000) |
| `DB_PATH` | ที่เก็บไฟล์ฐานข้อมูล (ค่าเริ่มต้น `data/taskboard.db`) |
| `SETUP_KEY` | ถ้าตั้งไว้ ต้องกรอกรหัสนี้ตอนสร้างผู้จัดการคนแรก **แนะนำให้ตั้งเมื่อเปิดบนอินเทอร์เน็ต** |
| `INGEST_KEYS` | ระบบอื่นที่ส่งเวลาใช้งานเข้ามาได้ รูปแบบ `erp=<รหัสลับ 24+ ตัว>,crm=<รหัสลับ>` ดู `erp-integration/README.md` |
| `TZ_OFFSET_MIN` | เขตเวลาที่ใช้ตัดวันในรายงานชั่วโมง (ค่าเริ่มต้น 420 = เวลาไทย) |
| `COOKIE_SECURE=1` | บังคับคุกกี้แบบ Secure (ใช้เมื่อเปิดผ่าน HTTPS) |

## สิทธิ์การใช้งาน
| | ผู้จัดการ | พนักงาน |
|---|---|---|
| เห็นงาน | ทุกงาน ทุกคน | เฉพาะงานที่เกี่ยวข้องกับตัวเอง |
| สร้างงาน | มอบให้ใครก็ได้ | สร้างงานของตัวเอง |
| แก้ชื่อ/รายละเอียด/deadline | ทุกงาน | งานที่เกี่ยวข้อง (ยกเว้นที่เสร็จแล้ว) |
| เปลี่ยนผู้เกี่ยวข้อง | ได้ | ไม่ได้ |
| ย้ายสถานะ รอทำ/กำลังทำ/รอตรวจ | ได้ | ได้ |
| ปิดงานเป็น "เสร็จแล้ว" / เปิดงานใหม่ / ลบงาน | ได้ | ไม่ได้ |
| หน้าจัดการผู้ใช้ รหัสเชิญ | ได้ | ไม่เห็น |

- ทุกการแก้ไขบันทึกประวัติ: ใครแก้ แก้อะไร (ค่าเดิม → ค่าใหม่) เมื่อไหร่
- ถ้ามีสองคนเปิดแก้งานเดียวกัน คนที่บันทึกทีหลังจะได้รับแจ้งให้โหลดใหม่ ไม่เขียนทับกันเงียบๆ
- การสมัคร (register) ต้องใช้รหัสเชิญจากผู้จัดการ ใช้ได้ครั้งเดียว อายุ 7 วัน หรือผู้จัดการสร้างบัญชีให้เอง
- ปิดใช้งานผู้ใช้ / เปลี่ยนตำแหน่ง / รีเซ็ตรหัสผ่าน จะทำให้ผู้ใช้นั้นถูกออกจากระบบทันที
- ต้องมีผู้จัดการที่ใช้งานอยู่อย่างน้อย 1 คนเสมอ

## ชั่วโมงทำงาน (นับอัตโนมัติ)
- เบราว์เซอร์ส่งสัญญาณทุก 30 วินาที **เฉพาะตอนที่เปิด TaskBoard อยู่หน้าจอและมีการขยับเมาส์/พิมพ์/แตะหน้าจอภายใน 2 นาทีที่ผ่านมา** เซิร์ฟเวอร์บันทึกเป็น "นาทีที่ใช้งาน" (1 แถวต่อ 1 นาที) ชั่วโมง = จำนวนนาที ÷ 60
- เมนู "ชั่วโมงทำงาน": ผู้จัดการเห็นตารางรายวัน/รายสัปดาห์ของทุกคน กดชื่อเพื่อดูช่วงเวลาที่ใช้งานแต่ละวัน พนักงานเห็นเฉพาะของตัวเอง ("ชั่วโมงของฉัน")
- ไม่มีขั้นตอนให้ผู้ใช้กดรับทราบ ระบบนับตั้งแต่ล็อกอิน พนักงานเห็นเวลาของตัวเองได้ตลอด (ป้ายบนแถบเมนูและเมนู "ชั่วโมงของฉัน") และหน้ารายงานมีข้อความอธิบายว่านับอะไร
- ข้อมูลผูกกับบัญชีรายบุคคลจึงเป็นข้อมูลส่วนบุคคลตาม PDPA ควรแจ้งพนักงานล่วงหน้าผ่านนโยบายบริษัทหรือเอกสารจ้างงาน (ให้ HR/ฝ่ายกฎหมายตรวจ)
- ไม่จับภาพหน้าจอ ไม่บันทึกสิ่งที่พิมพ์ ไม่ดูโปรแกรมหรือเว็บอื่น
- ตัวแปร `TZ_OFFSET_MIN` กำหนดเขตเวลาที่ใช้ตัดวัน (ค่าเริ่มต้น 420 = เวลาไทย UTC+7)

**ข้อจำกัดที่ต้องรู้:** ตัวเลขนี้คือ "เวลาใช้งานในแอป" ไม่ใช่เวลาเข้า-ออกงาน งานที่ทำนอกแอปไม่ถูกนับ และมีเวลาเกินจริงได้ไม่เกิน ~2 นาทีต่อช่วงที่หยุดใช้งาน ผู้ใช้ที่มีความรู้เทคนิคอาจส่งสัญญาณปลอมได้ จึงไม่ควรใช้เป็นหลักฐานเดียวในการคำนวณค่าจ้างหรือลงโทษ

**ต่อกับระบบอื่น (เช่น ERP):** ดูคู่มือและสคริปต์ที่ `erp-integration/`

## ความปลอดภัยที่ทำไว้แล้ว
รหัสผ่านเข้ารหัสแบบ scrypt + salt, คุกกี้ HttpOnly + SameSite=Strict, ป้องกัน CSRF ด้วย header, จำกัดการเดารหัสผ่าน (8 ครั้ง/10 นาที ต่อชื่อผู้ใช้), Content-Security-Policy, ตรวจสิทธิ์ที่ฝั่งเซิร์ฟเวอร์ทุกคำขอ

**ที่ควรทำเพิ่มก่อนใช้จริง:** เปิดผ่าน HTTPS เท่านั้น, ตั้ง `SETUP_KEY`, สำรองไฟล์ฐานข้อมูลสม่ำเสมอ, ไม่มีระบบ "ลืมรหัสผ่านทางอีเมล" (ผู้จัดการรีเซ็ตให้)
